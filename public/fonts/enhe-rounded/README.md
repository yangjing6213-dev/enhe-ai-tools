# ENHE Rounded — complete rounded web font

The user approved replacing the browser-rejected Alimama face with a similar working rounded font on 2026-10-18.

- Original: **ChillRoundF Regular v3.200 (寒蝉全圆体)** by ChillType.
- Official release: https://github.com/Warren2060/ChillRound/releases/tag/v3.200
- Source asset: `ChillRoundFRegular.ttf` (6,205,268 bytes).
- Source SHA-256: `7ccfc2cd0e971edeac7f65516df8db379f0f84d0d8ff79ee4dfe377956418d3b`.
- License: SIL Open Font License 1.1, reproduced verbatim in `OFL.txt`.
- Official license: https://github.com/Warren2060/ChillRound/blob/main/LICENSE

The complete font was compressed to WOFF2 using FontTools. **No subsetting was performed**: all 15,865 glyphs and 14,304 Unicode mappings remain. Before/after recording-pen outline hashes, horizontal metrics, glyph order and Unicode mappings were verified identical. The identity was renamed to `ENHE Rounded` / `ENHERounded-Regular` because the license reserves the original font names. Author copyright and license records remain intact. This derived file is distributed under the same OFL, without claiming author endorsement.

Web file: `ENHERounded-Regular-full-bc07a6d90a6685fe.woff2` (2,612,604 bytes). SHA-256 and preservation evidence are in `manifest.json`. The website declares the real static Regular weight, 400; browser font synthesis supplies existing bold UI styles without adding a second full download. Layout and font sizes are unchanged.

The original Alimama assets are preserved without modification but are no longer referenced by application CSS.
