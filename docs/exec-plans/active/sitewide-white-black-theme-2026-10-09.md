# 全站白底黑字与发布

状态：实现与本地验证已完成；发布结果以本地审计回执记录。

## 目标与范围

- 目标：让 ENHE 所有主要界面和卡片使用白色背景，并将原有白色、灰色文字改为黑色。
- 保留：蓝色品牌强调、可读的成功/警告/错误颜色和现有页面内容。
- 不涉及：支付逻辑、订单数据、字体、页面文案、数据库或生产密钥。
- 发布范围：只包含本任务新增/修改的计划、测试和样式/主题文件；不包含其他工作区里的未提交内容。

## 验收标准

1. 浏览器处于深色系统偏好时，网站仍保持白底黑字。
2. 页面、卡片、弹出层与页尾背景为白色；白色/灰色文字不再以浅色呈现。
3. 蓝色按钮与状态提示仍清晰可读，主要桌面和手机页面无明显视觉回归。
4. 相关测试、类型检查、Lint、构建和发布脚本门禁通过；推送与腾讯云版本号一致。

## 执行步骤

1. 编写白底黑字与固定浅色的回归测试，并确认测试按预期失败。
2. 调整主题变量、残留浅色文字/深色表面和主题切换入口；复跑定向与全量验证。
3. 复核精确变更清单，完成普通 GitHub 推送、腾讯云部署及线上页面检查。
