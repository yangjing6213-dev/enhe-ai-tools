# ENHE 评论、用户资料与后台可读性修复

日期：2026-10-11

## 目标
- 后台评论支持真正删除，并在操作完成后立即更新列表和按钮状态。
- 注册时采集用户名；用户中心允许修改用户名和上传头像。
- 产品评论支持 1–5 星；后台和首页评论展示真实用户名、头像、产品、评分和正文。
- 修复用户管理长文本错位，并统一检查蓝底按钮白字对比度。

## 已确认的原因
- 评论管理将“删除”映射为 `status = deleted`，没有删除数据库记录；评论列表默认仍包含该状态。
- `FormSubmitButton` 在点击后设置 `hasSubmitted`，但组件没有在服务器操作结束后复位，因此按钮会持续禁用直至页面重新挂载。
- `User` 已有 `nickname` 和 `avatar` 字段；注册目前把邮箱前缀写入昵称，用户中心没有个人资料编辑入口。
- `Comment` 尚无评分字段，详情页评论表单只提交正文；首页评论映射也使用通用占位用户名。

## 边界
- 使用本机临时数据库和隔离浏览器夹具验证，不写入生产评论、用户或订单。
- 昵称复用现有 `nickname` 字段；评分新增可为空的 1–5 整数字段，旧评论不补造评分。
- 头像仅允许登录用户上传小型 PNG/JPEG/WebP 图片；保存到现有公开上传存储。
- 只修改本任务相关代码与测试；保留主工作目录里的既有改动。
- 推送和部署由用户当前请求授权。

## 验收与验证
1. 用失败测试证明硬删除、按钮复位、注册/编辑资料、评分校验和公开评论字段缺失；实现后验证对应逻辑与迁移。
2. 浏览器检查评论管理、用户列表/资料、产品评论和首页；确认长文本不挤坏布局，蓝色主按钮为白字。
3. 运行相关测试、类型检查、Lint、构建和发布脚本；部署后仅做线上只读健康检查。
