# ENHE 后台模块复核与评论展示

日期：2026-10-11

## 目标
- 盘点并清理服务器上可安全回收的旧镜像空间。
- 核查后台模块的关键数据和操作路径，修正卡片纵向布局与蓝底白字问题。
- 在评论管理中增加“展示/取消展示”控制，并让获准展示的评论进入首页评论窗口。
- 完成有代表性的本地浏览器、接口/逻辑测试及生产只读健康检查后推送和部署。

## 边界与风险
- 服务器清理已经完成：删除超过 30 天、无容器引用的 ENHE 镜像；当前版本、即时回退镜像、容器和数据库卷已保留。
- 不对生产订单、付款、评论或用户执行写入、删除或退款；写操作用本地隔离测试数据验证。
- 保留主目录已有未提交改动；仅在干净的产品后台工作区修改。
- 上线由本任务用户授权。现有 `isPinned` 专用于产品页置顶，无法单独表达首页展示，因此新增独立 `show_on_homepage` 布尔字段和仅增列迁移；默认关闭，不回填或公开任何既有评论。

## 验收标准
- 后台各模块的卡片在窄屏和桌面按上下阅读顺序排列，蓝色背景上的文字具有白色高对比度。
- 管理员可在评论管理启用或取消首页展示；未审核通过或被删除的评论不会公开显示。
- 首页评论窗口仍有默认内容，数据库不可用时不导致首页失败；启用展示的合规评论可进入展示列表。
- 既有后台订单、产品发布、支付、评论等关键流程在隔离测试中通过；生产只做只读健康验证。
- 相关测试、类型检查、Lint、构建、差异审查通过后再推送部署。

## 执行记录
- 已盘点并清理生产 Docker：移除超过 30 天且无容器引用的 ENHE 镜像；根盘使用率 94%→82%，可用空间 12GB→33GB；保留当前镜像、即时回退镜像、容器及数据库卷。清理后线上应用、worker、scheduler 健康，首页与产品详情页返回 HTTP 200。
- 已增加管理员评论首页展示开关。仅审核通过的评论可启用；取消审核时自动撤销展示。首页最多读取 5 条已审核展示评论，不读取账号字段；中英文首页共用，不可用数据库时保留原展示。
- 已将后台看板与说明卡片纵向排布；蓝色背景使用白字。补充本地只读 Playwright fixture 检查，包含首页评论隐私、蓝色操作按钮和纵向卡片。
- 已完成逻辑测试、后台浏览器回归、Lint、类型检查和 schema 校验。隔离 PostgreSQL 已从空数据库成功应用全部 50 个迁移；仅提供 `SEO_AUDIT_TEST_DATABASE_URL` 后，全部 Vitest 为 2,833/2,833 通过（包含订单、退款、支付和删除保护测试）。后台视觉 E2E 最终 27 项均通过；初轮两项失败分别是提示文字类冲突（修正后通过）和本地站点内存重启导致的连接中断（单独复测通过）。浏览器夹具拦截写请求；数据库集成测试只操作一次性本机测试库，结束后已删除临时容器；未对生产订单、评论或用户写入。
- 已完成差异审查及项目发布脚本验证；代码提交 `ce26304343e5bd071d6e293f607e4d05fcf11873` 已推送至 `codex/enhe-recovery-baseline` 并部署。迁移成功，应用、worker、scheduler 健康；首页与产品详情 HTTP 200，未登录访问管理入口按预期跳转登录（HTTP 307）。
