# Phase 0.5 剩余输入

以下是仍真正需要用户或运维提供的输入；ZPAY 共用网关、支付宝/微信 type、默认支付宝、GET notify、查单和退款接口已确认，不再列为未知决策。

1. 生产部署 SHA、镜像 digest、数据库 migration 版本、Nginx 配置和对象存储/CDN 只读元数据。
2. 生产 File 元数据清单：storage、object key/path、公开/私有、关联 Tool、缓存策略；不提供文件内容或 secret。
3. ZPAY sandbox/测试商户验证能力：回调、查单、退款、重复通知、金额不匹配、权限补偿和对账样例。
4. Google/GitHub OAuth 应用状态、回调 URI、隐私政策 URL 和账号归属；不提供密钥到本阶段。
5. 真实价格、促销价、退款边界和 Explorer Pass 最终规则。
6. 真实购买评价、订单关联、用户确认、评分和头像许可。
7. 公司主体、地址、电话、官方社交账号最终值。
8. `/help`、`/updates`、Build Your Own X、AI 账号服务旧 URL 的流量/外链/收录数据。
9. Search Console、Analytics、站长平台只读导出及 AI 引用抽样查询集。
10. 第一批高保真设计稿、五款产品真实视频/字幕/封面。
