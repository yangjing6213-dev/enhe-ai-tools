# 1. 项目目标

## 1.1 总目标

将 ENHE 从当前较复杂、视觉不统一、搜索内容直接暴露给普通用户的网站，升级为：

> **面向普通 AI 用户的一站式 AI 平台，通过精致的 TypeShare 式设计、真实产品演示、清晰的信息架构与可落地的内容，帮助用户发现 AI 工具、AI 智能体、AI Skill、AI 趋势和实战方法，并最终让 AI 产生真实价值。**

## 1.2 五项同级目标

新版必须同时达到：

1. **UI 精致度**：页面比例、留白、排版、颜色、按钮、卡片、动效和状态细节达到高品质网站标准。
2. **用户体验**：路径更短、信息更清楚、功能更简单、移动端完整可用。
3. **页面架构**：栏目关系明确，用户能快速发现产品、Skill、资讯、趋势、教程和帮助。
4. **SEO**：主动优化搜索意图、内容质量、内部链接、索引结构、性能和结构化数据，而不是机械保留旧结构。
5. **GEO**：让搜索和 AI 系统更容易准确理解 ENHE、产品、Skill、资讯、趋势与品牌实体，同时保持自然的人类表达。

任何一项明显不合格，均不能正式上线。

# 2. TypeShare 参考边界

## 2.1 高保真参考范围

全站视觉和交互语言高度参考 TypeShare，包括：

- 大字号；
- 强留白；
- 暖白、近黑、鼠尾草绿、浅灰绿和少量黄色；
- 一个页面一个核心目标；
- 真实产品界面或演示；
- 简洁按钮；
- 克制卡片；
- 导航、分类菜单、登录页、列表页和内容页的视觉节奏；
- 动效时长、幅度、缓动与交互反馈；
- 桌面、平板和手机端的响应式逻辑。

首页以 TypeShare 首页作为高保真复刻目标；产品页参考 TypeShare Templates 页面；登录注册参考 TypeShare Sign In 页面。

不得复制 TypeShare 的：

- 源代码；
- CSS 文件；
- JavaScript；
- 图片；
- 视频；
- 字体文件；
- 图标资源；
- 用户头像；
- 用户评价；
- 品牌名称；
- 文案；

新版不继续沿用当前蓝紫渐变、霓虹光效和大面积玻璃拟态。ENHE 的独立识别度来自：

# 5. 全局视觉系统

## 5.1 初始配色方向

最终色值可在高保真设计阶段基于 TypeShare 实际视觉重新校准。当前基准：

| 用途 | 初始色值 |
|---|---|
| 页面主背景 | `#FDFDFD` |
| 卡片与内容背景 | `#FFFFFF` |

- 蓝紫渐变；
- 霓虹光效；

主按钮：

- 高度 44–48px；
- 左右内边距 22–28px；
- 圆角 6–8px；
- 鼠尾草绿背景；
- 白色文字；
- 不使用发光；
- 悬停变深并上移 1px；
- 按下缩放约 0.98；
- 加载状态宽度不跳动；
- 键盘焦点清晰可见。

首屏最多 1 个主按钮和 1 个次按钮。

功能说明：

### 01 无所不能版｜AI生成视频应用

> 本地完成文生视频、图生视频与视频增强，不受在线平台次数限制，打造更自由、更接近“无所不能”的视频创作体验。

### 02 InfiniteTalk

> 使用人物图片与音频，生成自然流畅的数字人口播视频。

### 03 AI语音生成

> 本地生成旁白、配音和多角色对话，不受在线次数与平台流程限制，打造更自由、更接近“无所不能”的声音创作体验。

### 04 Lumi-OS

> AI智能体不仅能够作为你的情感陪伴，还能协助整理任务、记忆信息和完成日常工作。

### 05 FaceSwap Studio

> 本地完成人物素材合成、效果预览与创作处理，不受在线平台限制，打造更自由、更接近“无所不能”的人像创作体验。

交互：

- 绝不自动切换产品；
- 左右按钮手动切换；
- 支持键盘左右键；
- 移动端支持手势滑动；
- 切换产品时暂停当前视频；
- 下一产品不自动播放；
- 显示 `01 / 05`；
- 视频按需加载，其他视频不预加载；
- 视频默认静音并支持字幕、暂停和全屏；
- 每个产品有真实 `<a>` 链接和独立详情页。

后台可配置：

- 五款产品；
- 顺序；
- 中文/英文视频；
- 封面；
- 功能说明；
- 产品链接；
- 显示/隐藏。

## 7.3 用户评价

视觉和交互：

- 自动滑动；
- 每 5 秒切换一条；
- 两侧淡出；
- 鼠标悬停暂停；
- 手动操作后约 6 秒恢复；
- 浏览器失去焦点时暂停；
- 减少动态效果开启时停止自动播放；
- 移动端一次突出一条。

生产规则：

- 正式上线的“真实购买用户评价”必须绑定真实用户、真实订单、真实评分和用户确认；
- 默认插画头像可作为系统默认头像，但不得暗示为真人照片；
- 未经真实订单和用户确认的数据只能用于开发、设计与验收环境，不得在生产站冒充已验证购买评价；
- 只有满足真实订单关联时，才可使用 Review/AggregateRating 结构化数据。

## 22.3 页面语义

所有核心页面：

- 唯一可见 H1；
- 合理 H2/H3；
- 核心内容服务端输出；
- 导航和卡片使用真实链接；
- 移动端不删除关键内容；
- 图片有自然 alt；
- 视频有标题、说明和字幕；
- 重要内容不只存在于图片、Canvas 或点击后状态。

## 22.4 结构化数据

按真实页面类型使用：

| 页面 | 建议类型 |
|---|---|
| 首页 | Organization、WebSite |

- 虚构评分；
- 隐藏评价；

## 22.6 robots 与 AI 搜索

公开页面允许主流搜索引擎和 OAI-SearchBot 抓取，除非后续基于官方最新政策另有确认。

私人页面的安全不能依靠 robots，必须使用服务端权限、私有存储、不可预测标识、禁止公共缓存和适当的 HTTP 状态。

## 22.7 URL 决策

每个旧 URL 必须被标记为：

```text

合并并 301
迁移到新 URL
410 删除
私有归档
继续 404
```

禁止：

- 所有旧 URL 跳首页；
- 无关 301；
- 多级重定向链；
- JavaScript 跳转替代服务端 301；
- 删除页面返回 200 空内容。

# 26. 动效与微交互

确认采用克制的 TypeShare 式动效。

基准：

| 行为 | 时长 |
|---|---:|
| 常规悬停 | 160–180ms |
| 按钮点击 | 120–160ms |
| 弹层 | 180–220ms |
| 卡片切换 | 240–300ms |
| 产品轮播 | 280–320ms |
| 内容入场 | 240–360ms |

原则：

- 优先 `transform` 与 `opacity`；
- 幅度 2–12px；
- 不造成 CLS；
- 不阻塞首屏；
- 支持 `prefers-reduced-motion`；
- 禁止复杂全站转场；
- 禁止鼠标跟随光效、粒子、持续闪烁、长时间数字滚动和大型视差。

首页首屏分层淡入；产品卡片悬停上移约 2px；深色菜单轻微淡入缩放；搜索弹层轻量出现；表单即时自然反馈。
