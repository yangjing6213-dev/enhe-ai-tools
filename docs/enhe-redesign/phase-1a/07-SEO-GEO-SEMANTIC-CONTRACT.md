# Semantic and discovery contract

Each page has one H1, a locale-appropriate `lang`, a unique title, semantic `header/nav/main/footer`, and ordinary links. Product cards are `article` records with one factual description and one distinct public detail URL. The software page keeps a visible `?page=2` pagination affordance so production can render crawlable pages without relying on client-only loading.

Before production wiring, add verified canonical/hreflang, robots, sitemap, and structured data from authoritative ENHE records. Do not invent ratings, prices, availability, authors, or delivery claims.
