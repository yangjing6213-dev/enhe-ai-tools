# Responsive, accessibility, and motion contract

Product grid columns are fixed at 4/3/2/1 for 1440/1024/768/390 (and 320) widths. Home content is centered at desktop; the yellow label is exposed only in the header brand region. Below 768px that header label is hidden and its H1-above counterpart is exposed through synchronized `hidden`/`aria-hidden` state. The stage is full width, controls move below it, and the stage height remains stable. `scrollWidth` must equal the viewport width at 390px.

Below 768px the new-release row uses 80vw cards and the featured row uses 84vw cards, both with 18px gaps, `overflow-x:auto`, `scroll-snap-type:x mandatory` and `scroll-snap-align:start`. The regions are focusable and support touch, trackpad, and ArrowLeft/ArrowRight input without automatic scrolling. All products remains one column. At 390px each horizontal region must have `scrollWidth > clientWidth`, while the document root must not overflow.

Reviews open on a centered middle record with both side cards fading, move every 5000ms, pause on hover, focus, pointer down, drag, and hidden-page state, and resume 6000ms after manual interaction. Product panels never auto-switch. Product transitions are 300ms; hover 170ms; category layer 200ms. The CSS `--motion-review` and `--motion-resume` tokens feed the JavaScript timers. JavaScript uses `matchMedia('(prefers-reduced-motion: reduce)')`; reduced motion creates no review timer and leaves manual controls available. Motion uses opacity/transform only.

Keyboard users receive a skip link, visible focus ring, arrow-key carousel/category/horizontal-row controls, Escape dismissal, semantic headings, labeled inputs, and 44px touch targets. The yellow focus token is paired with a near-black outer contrast guard so it remains visible on light and dark surfaces. Product media has descriptive alternative text and a visible name fallback; decorative provider icons are aria-hidden while their button labels remain complete. SVG avatars retain descriptive alternative text.
