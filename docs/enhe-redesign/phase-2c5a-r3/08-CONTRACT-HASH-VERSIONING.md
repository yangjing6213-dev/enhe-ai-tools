# Contract Hash Versioning

## Canonical hash algorithm

For each Markdown hash source:

1. Read the file as UTF-8 text.
2. Normalize every CRLF and lone CR to LF.
3. Remove all trailing line terminators and append exactly one final LF.
4. Hash the resulting UTF-8 bytes with SHA-256.
5. Encode the digest as lowercase hexadecimal.

The three source files do not contain their own hash values, preventing self-reference.
